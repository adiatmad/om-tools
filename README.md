# OM Tools

A small collection of Open Mapping data outputs. This repository currently contains mapper review metrics in CSV format.

## Contents

- `mapper_review_metrics.csv` — mapper/project review metrics, including review status, coverage, review requests, approvals, revisions, fixes, and related counts.

## Data

The CSV is intended for analysis or reporting workflows. Treat the values as project-specific exported data rather than a general-purpose dataset.
